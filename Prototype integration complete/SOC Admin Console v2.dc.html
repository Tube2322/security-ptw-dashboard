สร้าง QR Code ใหม่?

QR Code และลิงก์เดิมที่แจกไปแล้วจะใช้งานไม่ได้อีกทันที ต้องแจก QR/ลิงก์ใหม่ให้ผู้ใช้ พิมพ์ Regenerate เพื่อยืนยัน

ปิดใช้งาน User Entry Portal?

เมื่อปิดใช้งาน:

  • ผู้ใช้ทุกคนที่สแกน QR หรือเปิดลิงก์นี้จะกรอกข้อมูลไม่ได้ทันที
  • หน้ากรอกข้อมูลจะแสดงข้อความ "ปิดใช้งานชั่วคราว" แทนแบบฟอร์ม
  • ข้อมูลที่บันทึกไว้ก่อนหน้านี้จะไม่หายและยังดูได้ตามปกติ
  • เปิดใช้งานกลับคืนได้ทุกเมื่อในหน้านี้
